# 🎬 BOM-MOVIE

> TMDB API를 활용한 반응형 영화 정보 웹 애플리케이션

🔗 **Demo**: (https://bomiii1.github.io/movie_app_26_07_23/)
📄 **GitHub**: https://github.com/bomiii1/movie_app_26_07_23

## 📖 프로젝트 소개

현재 상영작과 인기 영화, 개봉 예정작을 확인하고 원하는 영화를 검색할 수 있는 영화 정보 사이트입니다. 영화 상세 정보와 출연진, 감독, 예고편, OTT 정보를 제공하며 랜덤 영화 추천 기능도 지원합니다.

## ✨ 주요 기능

- 인기 영화 Hero Slider
- 현재 상영작, TOP 10, 개봉 예정작 조회
- 영화 제목 검색
- TOP 50 랜덤 영화 추천
- 영화 상세 정보, 예고편 및 OTT 정보 제공
- 배우 및 감독 프로필과 참여 작품 조회
- 비슷한 영화 추천
- 반응형 UI 및 404 페이지

## 🛠 Tech Stack

- React
- Vite
- React Router DOM
- Tailwind CSS
- Swiper
- TMDB API

## 📡 API

영화 데이터는 [TMDB API](https://www.themoviedb.org/)를 사용합니다.

This product uses the TMDB API but is not endorsed or certified by TMDB.
